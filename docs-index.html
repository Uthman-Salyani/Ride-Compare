RideCompare API (1.0.0)

Download OpenAPI specification:Download

Read-only API surface exposed to Voter Edu. All endpoints are GET. RideCompare's own product also has internal write endpoints (e.g. POST /bookings) used when a rider books directly through RideCompare's app, but those are not exposed to this partner since Voter Edu never books through us — see ENDPOINT_LIST.md Part D.

Return fare/ETA estimates across providers and ride types, filterable by ride type, sortable by ETA or fare

pickup and dropoff coordinates are required and validated, but fare.amount is currently each ride type's base fare only; it does not vary with distance or travel time.

query Parameters
pickup_lat
required
number <float>
Example: pickup_lat=-1.2864
pickup_lng
required
number <float>
Example: pickup_lng=36.8172
dropoff_lat
required
number <float>
Example: dropoff_lat=-1.3197
dropoff_lng
required
number <float>
Example: dropoff_lng=36.8271
type
string
Enum: "Boda" "Standard" "XL" "Comfort" "Delivery"
Example: type=Standard

Filter results to a single ride type (case-insensitive). Any other value returns 400.

sort
string
Enum: "eta" "fare"
Example: sort=eta

Sort field for the returned estimates, ascending. Any other value returns 400.
